# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please use
[GitHub's private vulnerability reporting](https://github.com/ndiayemady/Git-Support/security/advisories/new)
to report it responsibly. Do **not** open a public issue.

## Sensitive Information

**Never post the following in public issues:**
- Private keys or seed phrases
- Wallet credentials or passwords
- Government-issued IDs or personal documents

If you have already shared sensitive info in a public issue, please delete
the comment and rotate the compromised credentials immediately.
